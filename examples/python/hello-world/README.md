# Hello World - Python Example

A simple Python demonstration showing basic script structure and best practices.

## Description

This example demonstrates:
- Python function definitions
- Docstrings for documentation
- Main guard pattern
- F-string formatting

## Running

```bash
python3 hello.py
```

## Expected Output

```
Hello, World!
Hello, Mahesh!
Hello, Developer!
```

## Learning Points

1. **Main Guard**: `if __name__ == "__main__":` ensures code only runs when script is executed directly
2. **Docstrings**: Triple-quoted strings document functions
3. **Default Arguments**: Functions can have default parameter values
4. **F-strings**: Modern string formatting using f"..."
